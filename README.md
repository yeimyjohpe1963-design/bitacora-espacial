# Bitácora Espacial

Portal que muestra noticias reales de exploración espacial, con búsqueda por tema. Hecho con React, Vite y JavaScript, con un sistema de diseño en CSS escrito a mano.

## Cómo correrlo

1. Instala las dependencias:

   npm install

2. Copia `.env.example` a `.env` (la URL de la API ya viene lista).

3. Inicia el servidor de desarrollo:

   npm run dev

   Abre http://localhost:5173

## API

Datos de [Spaceflight News API](https://api.spaceflightnewsapi.net/v4), gratuita y sin clave.# bitacora-espacial
